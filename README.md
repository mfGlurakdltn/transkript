# Audio Transkription

Transkribiert Audiodateien (mp3, wav, m4a, ...) lokal mit OpenAI Whisper auf Deutsch.

## Verwendung

1. Audiodatei hochladen
2. Modell wählen (`medium` = gute Balance, `large` = maximale Genauigkeit)
3. „Transkribieren" klicken
4. Text kopieren oder als `.txt` herunterladen
